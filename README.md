# South African Transport Efficiency & Sustainability Analysis

## Project Overview

This independent data science project investigates South Africa's transport system using historical transport, economic, population and energy-related data.

The project aims to understand how passenger and freight transport have evolved, explore available indicators of transport efficiency and sustainability, and identify opportunities for data-driven improvements.

The analysis uses the Transport Starter Data Kit (TSDK) for South Africa.

## Problem Statement

South Africa's transport sector faces challenges relating to efficiency, sustainability and the availability of reliable transport information.

Historical transport data is spread across different sources, years and measurement methods. This makes it difficult to compare transport activities, understand long-term trends and identify areas requiring further investigation.

This project uses data analysis to explore these challenges and provide evidence-based insights.

## Project Objectives

- Analyse historical passenger and freight transport activity.
- Investigate changes in transport modes and vehicle fleets.
- Explore relationships between transport indicators, population and GDP.
- Examine available energy and sustainability indicators.
- Identify data limitations and potential areas for improvement.
- Present findings through an interactive dashboard.

## Dataset

**Source:** Transport Starter Data Kit – South Africa (2022)

**Data repository:** https://doi.org/10.5281/zenodo.6540022

The dataset contains historical indicators relating to:

- Passenger transport
- Freight transport
- Vehicle fleets
- Population
- GDP
- Energy-related indicators

Data availability varies between indicators and years. Some values are estimates or modelled figures, so their original sources and limitations will be considered during analysis.
